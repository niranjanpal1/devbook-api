# DevBook API 🚀

MERN stack social media backend with JWT + OTP authentication.

## ✨ Features
- **Authentication**: Register, Login, OTP Email Verification
- **User System**: Profile, Follow/Unfollow 
- **Post CRUD**: Create, Like, Comment, Delete Posts
- **Security**: JWT Token, bcrypt Password Hash, Protected Routes
- **Tech Stack**: Node.js, Express.js, MongoDB, Mongoose

## 🛠️ Tech Stack
**Backend**: Node.js, Express.js, MongoDB, Mongoose  
**Auth & Security**: JWT, bcryptjs, nodemailer  
**Tools**: dotenv, cors, express-validator, nodemon
